# SISMID 2026: Human-AI Teaming Approach to ID Modeling

This repository hosts the course materials for the **SISMID 2026 Human-AI Teaming Approach to Infectious Disease Modeling** module.

The website is published with GitHub Pages and provides:

- Module overview and learning goals
- Preparation instructions and required software setup
- Additional resources and data sources
- Materials for each of the three workshop days
- Forecasting, model evaluation, and human-AI teaming activities

## Website

Visit the course site here:

https://dma-prime.github.io/SISMID-2026-Human-AI-Teaming-Approach-to-ID-Modeling/

## What you'll find

- **Overview** of the module structure and schedule
- **Preparation** guidance for R, RStudio, VS Code, Git, GitHub, and GitHub Copilot
- **Additional resources** for participants
- **Day 1, Day 2, and Day 3 materials**
- Workshop activities covering:
  - Infectious disease forecasting
  - AI and human-AI teaming concepts
  - Data cleaning and preparation
  - Prompting for AI-assisted coding
  - Forecasting labs
  - Model evaluation and refinement

## Repository purpose

This repo is designed to support a hands-on training module that combines:

- infectious disease modeling
- collaborative coding workflows
- AI-assisted analysis
- reproducible research practices

## Local development

If you want to explore the site locally, open the `docs/` folder in a browser or serve it with any static file server.
